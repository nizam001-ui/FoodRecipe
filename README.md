# Foodie – Recipe Management Application

**Foodie** is a React Native recipe application developed as part of a practical mobile application development lab.

### Technologies Used
- React Native
- Expo
- JavaScript
- React Navigation
- Redux Toolkit
- AsyncStorage

### Main Features
- Welcome screen with animation
- Recipe browsing and category filtering
- Recipe details with ingredients and cooking instructions
- Add, edit, and delete custom recipes
- Save and remove favorite recipes
- Local storage for custom recipes
